About This Project

Digital Signature & Document Verification System: an Introduction to Cyber Security project.

Objectives

  • Demonstrate how digital signatures provide integrity and authenticity.
  • Let users generate keys, sign documents and verify them.
  • Explain every verification result in plain language.
  • Follow secure coding practice: no private key storage, validated input, safe errors.

Technology

  • Backend: Python, FastAPI, Pydantic
  • Cryptography: the cryptography library
  • Algorithms: RSA-2048, RSASSA-PSS, SHA-256
  • Database: SQLite via SQLAlchemy
  • Frontend: HTML, CSS, vanilla JavaScript

Security design

  • Private keys and documents are never stored or logged
  • Optional passphrase encryption of private keys
  • Input validation and size limits (5 MB files)
  • ORM queries only (no SQL injection)
  • Safe error messages, no stack traces
  • Basic rate limiting

Limitations

  • No certificate authority: the registry shows a name next to a key but does not prove real-world identity.
  • Signing happens on the server for demo simplicity; a real product would sign on the user's device.
  • This is an educational tool and not a legally recognised e-signature service.
  • Rate limiting is in memory and suited only to a single local server.
