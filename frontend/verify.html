Verify a Document

Provide the document you received, the signature file, and the signer's public key. The system tells you whether the signature is valid and why.

Or upload / paste a public key below (pasted key takes priority).

What gets checked

  1. Document integrity: is the file exactly the one that was signed?
  2. Signer key match: is this the public key the signer says they used?
  3. Signature authenticity: does the signature verify mathematically?

All three must pass for a VALID result. Try verifying the tampered sample from the Learn page to see a failure explained.
